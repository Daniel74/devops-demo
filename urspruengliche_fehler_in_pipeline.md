| Symptom / Risiko                                                                                                                                                      | Ursache                                                                                                                                            | Fix                                                                                                                                                                                         |
| :-------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **1. Python-Version Fehler:** Run bricht ab (`setup-python` meldet unvollständige Version `3.1`)                                                                      | Die Versionsnummer `3.10` steht ohne Anführungszeichen                                                                                             | Anführungszeichen setzen: `python-version: "3.10"`                                                                                                                                          |
| **2. Test-Fehler:** `pytest: command not found` beim Ausführen der Tests.                                                                                             | Der Test-Step (`pytest`) ist vor dem Installations-Step der Dependencies platziert.                                                                | Reihenfolge tauschen: Zuerst `python -m pip install -r requirements.txt`, dann `python -m pytest -v` ausführen                                                                              |
| **3. Installations-Fehler:** `Could not open requirements file: [Errno 2] No such file or directory: 'requirement.txt'`.                                              | Tippfehler im Dateinamen der Requirements (`requirement.txt` statt `requirements.txt`).                                                            | Dateinamen korrigieren auf `requirements.txt`.                                                                                                                                              |
| **4. Build-Fehler & Unvollständige Pipeline:** Build schlägt fehl (`No such file or directory: 'src/'`) UND läuft unabhängig von Testergebnissen.                     | Der `build`-Job nutzt kein `actions/checkout@v4` (Code fehlt) und besitzt keine Job-Abhängigkeit (`needs: test`).                                  | `actions/checkout@v4` im `build`-Job ergänzen und `needs: test` hinzufügen.                                                                                                                 |
| **5. Sicherheitsrisiko & Falsche Deploy-Auslösung:** Secret-Wert wird im Klartext im Log angezeigt und Deployments starten bei jedem Pull Request auf allen Branches. | Secret wird direkt per `echo` ausgegeben. Zudem fehlen Bedingungen (`if: github.ref == 'refs/heads/main'`), `environment: production` und `needs`. | `needs: [test, build]` setzen, `if: github.ref == 'refs/heads/main'`, `environment: production` und Secret nur als Env-Variable nutzen ohne den Wert auszugeben (z. B. `${#DEPLOY_TOKEN}`). |
| **6. Caching-Problem:** Der Pip-Cache wird nie aktualisiert; bei neuen Dependencies werden veraltete Pakete geladen.                                                  | Der Cache-Key ist statisch (`key: pip-cache`) ohne Hash-Prüfung.                                                                                   | Dynamischen Key mit `hashFiles('requirements.txt')` und `restore-keys` verwenden.                                                                                                           |
